# Муравьиный алгоритм (ACO)

## Чтоб запустить надо:

1. Создать объект класса  ACO(start: GridPoint, sightsForVisit: [Sight], grid: [[CellType]]), где 
    start - точка на которой изначально стоит пользователь,
    sightsForVisis - достопримечательности, которые пользователь хотел бы посетить, 
    grid - наша карта.
    
2. Вызывать метод optimalPath() -> [GridPoint], внтури метода выполняется стандартный муравьиный алгоритм и возвращется массив путь, который нужно проделать для того чтобы обойти все достопримечательности и вернуться обратно в начальную точку.

## Некоторые настройки, если что то не устраивает: 
1. private let alpha: Double = 2.0 - регулирует значимость длины пути
2. private let beta: Double = 1.0 - регулирует значимость кол - ва феромонов 
3. private let evaporation: Double = 0.3 - скорость испарения феромонов, но вряд ли ты будешь это трогать, однако, чем больше тем меньше значимость феромонов
