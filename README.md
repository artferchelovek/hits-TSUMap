# TSUMap

Умная карта кампуса Томского государственного университета. Навигация по территории ТГУ с интеллектуальным поиском заведений, построением оптимальных маршрутов и персонализацией на основе машинного обучения.

---

## Возможности

### Навигация по кампусу
- Построение маршрутов с использованием алгоритма A*
- Визуализация препятствий и зон 
- Отслеживание положения пользователя на карте в реальном времени
- Автоматическая перестройка маршрута при отклонении от пути 
- Индикация пройденной и оставшейся части маршрута

### Интеллектуальный поиск
- Мгновенный поиск по кафе, коворкингам и достопримечательностям
- Фильтрация по названию и адресу
- Установка найденного места как старт/конец маршрута

### Рекомендательная система
- Нейронная сеть для рекомендаций мест на основе предпочтений
- Дерево решений для определения подходящего типа заведения

### Оптимизация маршрутов
- **Гастро-тур**: генетический алгоритм для построения оптимального маршрута по заданным блюдам с учётом времени работы заведений.
- **Туристический маршрут**: муравьиный алгоритм (ACO) для посещения выбранных достопримечательностей

### Кластеризация
- Алгоритмы K-Medoids и DBSCAN для группировки заведений
- Визуализация зон на карте

## Технологии

- **SwiftUI** — UI фреймворк
- **MapKit** — карты
- **CoreLocation** — геопозиция
- **A\*** — поиск кратчайшего пути
- **Генетический алгоритм** — оптимизация гастро-тура
- **ACO** — оптимизация туристического маршрута
- **Нейронная сеть** — рекомендации

## Запуск

1. Открой `TSUMap.xcodeproj` в Xcode
2. Выбери симулятор или устройство
3. Запусти проект (Cmd + R)

---

## Использование

1. Разреши доступ к геопозиции при первом запуске
2. Укажи стартовую точку — тапни на карте или используй поиск
3. Выбери место назначения
4. Следуй маршруту — приложение отслеживает твоё положение
5. Используй дополнительные функции:
   - **Гастро-тур** — подбери блюда, алгоритм построит маршрут
   - **Туристический маршрут** — выбери достопримечательности
   - **Зоны еды** — кластеризация кафе
